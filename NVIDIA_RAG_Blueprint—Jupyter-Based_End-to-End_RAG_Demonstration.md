# NVIDIA RAG Blueprint — Jupyter-Based End-to-End RAG Demonstration

## 1. Overview

This document records the **successful end-to-end demonstration** of the NVIDIA RAG Blueprint running on an RKE2 Kubernetes environment.

The objective was to:

1. Deploy and access JupyterLab securely from a workstation.
2. Access the internal RAG and Ingestor services from Jupyter.
3. Upload a PDF document through the Ingestor API.
4. Verify successful document ingestion.
5. Submit a question to the RAG service.
6. Receive a grounded response generated by the NVIDIA Nemotron model.
7. Confirm that retrieved citation results were returned with the response.

The demonstration was successfully completed using:

**Document:** `toc.pdf`

**Model:** `nvidia/nemotron-3-super-120b-a12b`

# 2. Environment Architecture

The RAG Blueprint, Ingestor, and JupyterLab components run inside the RKE2 Kubernetes environment.

The workstation does **not** directly access the internal RAG or Ingestor services. Instead, JupyterLab is exposed locally through an SSH tunnel to the RKE2 server.


This approach kept the RAG and Ingestor services internal to Kubernetes.

# 8. Create a New Collection and Upload PDF Documents

The RAG pipeline supports separate knowledge bases through collections. In this demonstration, a dedicated collection named `blt_library` is used for Byte Latent Transformer research material.

## 8.1 Create the New Collection

Set the collection name and the internal vector-database endpoint used by the RAG deployment:

```python
COLLECTION_NAME = "blt_library"
VDB_ENDPOINT = "http://rag-eck-elasticsearch-es-default:9200"
```

Create the collection through the Ingestor API:

```python
collection_payload = {
    "vdb_endpoint": VDB_ENDPOINT,
    "collection_name": COLLECTION_NAME,
    "description": "Knowledge base for Byte Latent Transformer research material",
    "tags": [
        "ai",
        "llm",
        "research",
        "blt"
    ],
    "metadata_schema": []
}

response = requests.post(
    f"{INGESTOR_URL}/collection",

    timeout=60

print("HTTP Status:", response.status_code)

```

Verify the collection:

## 8.2 Upload All PDF Files from a Specified Directory

The following notebook workflow discovers every `.pdf` file in a specified directory and submits each file to the same collection.

Set the directory containing the PDF documents:

```python
from pathlib import Path

PDF_DIRECTORY = Path("/home/jovyan/work/pdfs")

pdf_files = sorted(
    p for p in PDF_DIRECTORY.iterdir()
    if p.is_file() and p.suffix.lower() == ".pdf"
)

print(f"PDF directory: {PDF_DIRECTORY}")
print(f"PDF files found: {len(pdf_files)}")

for pdf in pdf_files:
    print(f" - {pdf.name}")
```

Example directory:

```text
/home/jovyan/work/pdfs/
├── blt-paper.pdf
├── blt-results.pdf
├── transformer-paper.pdf
└── research-notes.pdf
```

Submit every PDF to the new collection:

```python
import json
import requests

ingestion_tasks = {}

for file_path in pdf_files:

    metadata = {
        "collection_name": COLLECTION_NAME,
        "blocking": False,
        "split_options": {
            "chunk_size": 512,
            "chunk_overlap": 150
        },
        "custom_metadata": [],
        "generate_summary": False,
        "documents_catalog_metadata": [],
        "summary_options": None,
        "enable_pdf_split_processing": False,
        "pdf_split_processing_options": {
            "pages_per_chunk": 16
        }
    }

    print(f"Uploading: {file_path.name}")

    with open(file_path, "rb") as f:
        response = requests.post(
            f"{INGESTOR_URL}/documents",
            files={
                "documents": (
                    file_path.name,
                    f,
                    "application/pdf"
                )
            },
            data={
                "data": json.dumps(metadata)
            },
            timeout=120
        )

    response.raise_for_status()

    result = response.json()
    task_id = result["task_id"]

    ingestion_tasks[file_path.name] = task_id

    print(f"HTTP Status: {response.status_code}")
    print(f"Task ID: {task_id}")
    print()
```

The `ingestion_tasks` dictionary maintains the task ID for each PDF:

```python
print(ingestion_tasks)
```

Example:

```text
{
    'blt-paper.pdf': '...',
    'blt-results.pdf': '...',
    'transformer-paper.pdf': '...'
}
```

# 10. Query the RAG Pipeline

After successful ingestion, the notebook submitted a question to the RAG server.

The successful request path was the RAG generation endpoint:

```text
http://rag-server:8081/v1/generate
```

The request used the knowledge base and reranking:

```python
import requests

question = "What is this document about?"

payload = {
    "messages": [
        {
            "role": "user",
            "content": question
        }
    ],
    "use_knowledge_base": True,
    "collection_names": ["multimodal_data"],
    "enable_reranker": True,
    "enable_citations": True
}
```

The request was sent as a streaming HTTP request:

```python
with requests.post(
    f"{RAG_BASE}/generate",
    json=payload,
    stream=True,
    timeout=300
) as r:
    print("HTTP Status:", r.status_code)
    r.raise_for_status()

    for line in r.iter_lines(decode_unicode=True):
        if not line:
            continue

        if line.startswith("data: "):
            line = line[6:]

        if line == "[DONE]":
            break

        print(line)
```

The request successfully returned:

```text
HTTP Status: 200
```

The response identified the model as:

```text
nvidia/nemotron-3-super-120b-a12b
```

The response also contained:

```text
citations.total_results: 10
```

This confirmed that the RAG service returned retrieved document evidence alongside the generated response.
